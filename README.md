Этот репозиторий одновременно и профиль, и сайт [dosash.ru](https://dosash.ru): GitHub Pages публикует его из ветки `main` (домен задан в `CNAME`).

**Сайт**

- `index.html` — главная страница (обо мне, стримы, проекты, контакты)
- `socials.html` — все ссылки в одном месте
- `telegram_post.html` — отправка постов в Telegram-каналы без бэкенда
- `404.html` — страница ошибки
- `style.css`, `app.js`, `favicon.svg` — стили, скрипты и иконка

**Папки**

- [`projects/`](projects/) — роутеры, Minecraft-сервер, боты, self-hosted сервисы
- [`gaming/`](gaming/) — игровые заметки и конфиги
- [`content/`](content/) — материалы для блога и каналов
- [`resources/`](resources/) — закладки и полезные ресурсы
- [`books/`](books/) — книги и цитаты
- [`stream/`](stream/) — ассеты для OBS: фон, LUT, маски
