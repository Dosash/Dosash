## 🌐 Сайт

Этот репозиторий — одновременно и сайт [dosash.ru](https://dosash.ru): GitHub Pages публикует его прямо из ветки `main` (домен задан в `CNAME`).

- `index.html` — главная страница (обо мне, стримы, проекты, контакты)
- `socials.html` — все ссылки в одном месте
- `telegram_post.html` — утилита для отправки постов в Telegram-каналы без бэкенда
- `404.html` — страница ошибки
- `style.css`, `app.js`, `favicon.svg` — стили, скрипты и иконка сайта
