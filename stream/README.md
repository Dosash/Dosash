# 🎥 Стрим

Ассеты для OBS, которые я использую на стримах:

- [`background.png`](background.png) — фон сцены
- [`trent-18.cube`](trent-18.cube) — LUT для цветокоррекции (фильтр «Применить LUT» на источнике камеры)
- [`image-masks/`](image-masks/) — 21 PNG-маска формы для фильтра «Image Mask/Blend» (круг, шестиугольник, скруглённые рамки и т.д.)
