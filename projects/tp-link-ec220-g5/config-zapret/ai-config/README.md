# Zapret YouTube Bypass Strategy для Ростелекома

## 📚 Описание

Полное руководство по настройке **Zapret** (DPI-desync) для обхода блокировки YouTube на роутере **TP-Link EC220-G5 v2.0** при использовании провайдера **Ростелеком**.

Репозиторий содержит:
- Подробный анализ всех 13 стратегий обхода
- Готовые конфигурации для быстрого запуска
- Справочник по синтаксису и частым ошибкам

## 🚀 Быстрый старт (30 секунд)

### Для максимально ленивых:

```bash
# 1. SSH в роутер
ssh admin@192.168.0.1

# 2. Отредактируйте /opt/zapret/config
vi /opt/zapret/config

# 3. Замените NFQWS_OPT_DESYNC на это (нажмите i, вставьте, ESC, :wq):
NFQWS_OPT_DESYNC="--dpi-desync=split2"
NFQWS_OPT_DESYNC_QUIC="--dpi-desync=fake --dpi-desync-repeats=6"

# 4. Перезапустите
/etc/init.d/zapret restart

# 5. Ждите 30 секунд и откройте YouTube
```

### Если не работает:
- Попробуйте **Вариант 2** или **Вариант 3** из `zapret-quick-start-ru.md`
- Посмотрите `zapret-syntax-and-errors-ru.md` если есть ошибка синтаксиса

## ⚠️ ВАЖНЫЕ ПРАВИЛА

1. **После каждого изменения конфига:**
   - Перезапустите Zapret: `/etc/init.d/zapret restart`
   - Ждите 30 секунд перед тестированием
   - Откройте YouTube в браузере заново
   - Очистите кэш браузера (F12 → Storage → Clear All)

2. **Для TP-Link EC220 НИКОГДА не используйте:**
   - `--dpi-desync-repeats` больше 8
   - Стратегию #3 (fake+fakeddisorder) - перегрузит роутер
   - Стратегию #9 (Advanced multidisorder) - вызовет перезагрузку

3. **Если роутер зависает:**
   - Отредактируйте конфиг через SCP/SFTP (если SSH заблокирован)
   - Уменьшите значение `--dpi-desync-repeats` на 2
   - Удалите лишние позиции из `--dpi-desync-split-pos`

## 💬 Частые вопросы

### Q: Почему YouTube медленный?
**A:** Это не проблема Zapret - это **throttling** от Ростелекома. Используйте VPN как дополнение к Zapret.

### Q: Работает ли на других провайдерах?
**A:** Да! Стратегии написаны для Ростелекома, но большинство работают на МегаФон, Билайн, Теле2.

### Q: Почему роутер зависает?
**A:** Вы используете слишком высокие `repeats` или слишком сложные стратегии. Начните с Варианта 1.

### Q: Когда Zapret перестанет работать?
**A:** Когда Ростелеком обновит DPI. Обычно это происходит каждые 2-4 месяца. Следите за новыми версиями Zapret.

### Q: Можно ли одновременно использовать несколько стратегий?
**A:** Нет. Используйте `--new` флаг для разделения стратегий, но это удвоит нагрузку на процессор.
